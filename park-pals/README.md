# Park Pals

A cozy, mobile-friendly playground game built with plain Canvas 2D, CSS and JavaScript.

## Play loop

- every park day generates a random buddy (name, skin tone, hair, clothes)
- walk freely around a bright top-down park
- get close to playground activities and press `E` / `Space` or the on-screen `PLAY` button
- make five happy memories to complete the park day
- keep exploring or generate a new buddy and start again

## Activities

- swing
- slide
- sandbox / sandcastle
- seesaw
- football
- pond ducks

## Controls

Desktop: `WASD` / arrow keys, `E` / `Space` to interact.

Mobile: left thumb stick to move, `PLAY` button to interact.

## Technical notes

- zero runtime dependencies
- no downloaded art assets
- no build step
- responsive touch controls
- procedural character and environment drawing
- optional synthesized WebAudio feedback
